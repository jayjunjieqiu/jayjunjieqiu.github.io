{% if lang == 'zh' %}通用时序预训练{% else %}Universal temporal pretraining{% endif %}

{% if lang == 'zh' %}如何让预训练模型学习跨领域可迁移的时序模式，同时适应不同长度的历史与预测区间？{% else %}How can pretraining capture temporal patterns that transfer across domains while supporting different context and forecast lengths?{% endif %}

{% if lang == 'zh' %}设计并预训练 UTP，完成跨领域预测评估与组件消融实验。工作时间：2025 年 10 月至 2026 年 1 月。{% else %}Designed and pretrained UTP, and ran cross-domain forecasting evaluations and component ablations. October 2025 – January 2026.{% endif %}

{% if lang == 'zh' %}模型设计与预训练{% else %}Model design and pretraining{% endif %}

{% if lang == 'zh' %}UTP 使用 encoder-only 时序骨干：先对输入序列归一化并切分成不重叠的片段，再随机遮蔽历史前缀，使模型在训练时接触不同长度的有效上下文。预训练配置支持最多 2,048 步输入与 256 步预测。{% else %}UTP uses an encoder-only temporal backbone. Input sequences are normalized and split into non-overlapping patches; randomly masked history prefixes expose the model to varying amounts of context. The pretraining configuration supports up to 2,048 input steps and 256 forecast steps.{% endif %}

{% if lang == 'zh' %}可学习的 register token 分隔历史上下文与未来占位片段；骨干结合 partial RoPE 与 gated attention，多分位数预测头使用 pinball loss 学习概率预测。这一阶段专注时序模式，完整框架再通过下游空间适配注入领域信息。{% else %}A learnable register token separates context from future placeholders. Partial RoPE and gated attention form the backbone; a multi-quantile head uses pinball loss for probabilistic forecasts. This stage focuses on temporal patterns, with downstream spatial adaptation adding domain information in the full framework.{% endif %}

{% if lang == 'zh' %}如何检验跨领域迁移{% else %}Evaluating cross-domain transfer{% endif %}

{% if lang == 'zh' %}我在未纳入预训练的基准数据集上评估固定权重的零样本预测，覆盖 12→12 与 96→96 的历史／预测长度配置。这样可以直接检验预训练表征对新数据集的迁移表现。{% else %}I evaluated fixed-weight zero-shot forecasts on benchmarks excluded from pretraining, using 12→12 and 96→96 context/forecast settings to test transfer to unseen datasets.{% endif %}

{% if lang == 'zh' %}消融：历史前缀遮蔽的作用{% else %}Ablation: the role of history masking{% endif %}
