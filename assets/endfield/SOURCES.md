# Endfield website design assets

The contour texture and divider are original files from https://github.com/triplepiers/Typst-Endfield-CV-Template . The original template license is retained in TEMPLATE-LICENSE. The upstream origin of the contour image beyond that repository is unverified. contour.webp is a 1200px, 34KB web version; the 1.4MB original is not included.

The color bar and Gilroy/Novecento fonts are original resources referenced by stylesheets on https://endfield.hypergryph.com/ . Browser fallback fonts supply punctuation omitted by the website font subsets.

- Color bar: https://web.hycdn.cn/endfield/official-v4/_next/static/media/color-bar.1f0aa038.png
- Gilroy Medium: https://web.hycdn.cn/endfield/official-v4/_next/static/media/font/Gilroy-Medium.4f7868.ttf
- Gilroy ExtraBold: https://web.hycdn.cn/endfield/official-v4/_next/static/media/font/Gilroy-ExtraBold.9856d3.ttf
- Novecento Medium: https://web.hycdn.cn/endfield/official-v4/_next/static/media/font/Novecentosanswide-Medium.b77880.ttf
- Novecento Bold: https://web.hycdn.cn/endfield/official-v4/_next/static/media/font/Novecentosanswide-Bold.2e0acc.ttf

This is a personal academic website. It does not claim game affiliation or use fictional clearance levels. Original assets retain their respective rights. Retrieved 2026-10-13.

## Header geometric mark

`geometric-mark.svg` is a local vector tracing of the three-part geometric mark used in the official website operator section, not an official vector master. Source: https://web.hycdn.cn/endfield/official-v4/_next/static/media/star.c078a0a7.png (61 x 67 pixels). Subpixel contours were interpolated from the original alpha channel and simplified at a 0.32-pixel tolerance into three separate paths; fill changed to #111111 for the header. The small original is kept outside this repository. Retrieved 2026-10-16.
